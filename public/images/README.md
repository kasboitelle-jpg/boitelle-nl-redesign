# Beeldmateriaal (plekhouders)

Deze map is bedoeld voor later aan te leveren beeld:

- **Portretfoto van Mark Boitelle** — komt op de homepage in de hero-zone
  (zie `src/pages/index.astro`, de `.hero-visual`).
- **Klantlogo's** (VGZ, Dichterbij, Wageningen Universiteit, Politie Academie) —
  vervangen de tekst-plekhouders in `src/components/LogoStrip.astro`.

Zet de bestanden hier neer (bijv. `mark.jpg`, `logo-vgz.svg`) en verwijs ernaar
met `/images/<bestandsnaam>`. Tot die tijd toont de site nette plekhouders, zodat
het ontwerp compleet oogt zonder foto's.
